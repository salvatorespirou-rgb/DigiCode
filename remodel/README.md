# DigiCode homepage remodel — local review

Preview: http://127.0.0.1:5501/remodel/

This is a separate homepage concept. The production homepage and shared styles/scripts were not edited. No commit, push or deployment was performed.

Business direction reviewed from the current homepage, portfolio, ownership page, project structure and live homepage:
- Independent Australian web studio, hand-coded websites and commerce.
- Ownership of the website/platform as a key differentiator.
- Creator platforms, memberships, streaming, apps and browser games.
- Hosting, updates, SEO and ongoing direct developer communication.
- Client portal and commercial pathways already present in the existing site.

Design direction: graphite, pale lime, large editorial typography and a mathematically projected rotating 3D torus. Scroll changes its orientation, with pointer response, reveal transitions and a reading progress line. The light ownership section creates a strong tonal change after the cinematic hero. Existing FreshCuts and JEFFOS assets demonstrate breadth and remain explicitly labelled as concepts.

Controls: native scrolling; Pause motion button; system reduced-motion support. Animation pauses offscreen. Layout includes mobile breakpoints and keyboard focus states. Links open the existing local business pages; only the homepage is remodelled.

Validation: JavaScript syntax checked, preview returned HTTP 200, all local asset and navigation destinations checked. Browser visual/interaction testing has not been performed.

Files: index.html, remodel.css, remodel.js. live-reference.html is the retrieved public homepage used for research, not part of the remodel interface.
