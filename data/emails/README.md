# Contact Email Storage

This folder is reserved for one thing only: **email addresses, collected for the purpose of contacting people who've asked to hear from DigiCode** (for example, a future newsletter or mailing list signup).

## What is allowed to be stored here

- Email addresses, and nothing else.

## What must never be stored here

- Names, phone numbers, Discord usernames, project details, payment information, or any other personal information. Those live only in whatever email thread a client sent them through — never in a file in this repo.

## Why this folder exists

There is no backend or database for this site. If an email signup is ever added, this is the one place a list of addresses would live locally on the developer's machine — never anywhere client-facing, never committed to version control (see `.gitignore`), and never containing anything beyond the email address itself.

This matches the commitment made in the site's [Privacy Policy](../../privacy-policy.html): contact information is collected and stored for the sole purpose of contacting you, and nothing more.
