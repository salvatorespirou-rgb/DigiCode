# Velora Digital

Portfolio and business site for Velora Digital, a web design studio.

## Structure

- `index.html` — main page
- `css/style.css` — all styling
- `js/main.js` — mobile nav + small interactions
- `assets/images/` — logo and other images

## Running locally

Open this folder in VS Code, install the **Live Server** extension, then right-click `index.html` → "Open with Live Server". It auto-reloads on save.

If you don't have Live Server installed yet, you can also run `serve.ps1` (a tiny PowerShell static server, no installs needed) and open `http://localhost:5500`.
